# msAgent使用指南

进入交互式会话后，可以直接输入问题，也可以配合 `/` 命令和快捷键提升效率。

### 基础命令

| 命令 | 说明 |
|---|---|
| `/hotkeys` | 查看键盘快捷键说明。 |
| `/agents` | 打开 Agent 选择器。 |
| `/model` | 打开模型选择器。 |
| `/threads` | 浏览并恢复历史会话线程；已执行过 offload 的线程会显示 `[history offloaded]`。 |
| `/tools` | 查看当前可用工具。 |
| `/skills` | 浏览当前可用 Skills。 |
| `/mcp` | 管理 MCP 服务启用状态。 |
| `/loop` | 创建、查看或取消当前会话的定时任务。 |
| `/remember <content>` | 保存长期记忆，例如用户偏好、项目背景或后续会话需要持续参考的事实。 |
| `/showmemory` | 查看当前项目已保存的长期记忆。 |
| `/offload` | 压缩并卸载较早的会话消息。 |
| `/tool-output` | 打开最近一次可展开的工具输出。 |
| `/clear` | 清屏并开启新线程。 |
| `/exit` | 退出当前会话。 |

### 定时任务

定时任务用于在当前交互式会话仍在运行时，延迟或周期性地向 Agent 发送一条任务提示词。任务到期后会在会话空闲时执行：如果 Agent 正在处理上一条消息，或者输入框中已有未提交内容，则会等待到空闲后再运行。

请先以交互式方式启动：

```bash
msagent
```

定时任务仅在交互式会话中可用。`msagent "<message>"` 这类单次执行模式会在处理完消息后退出，不能用于创建会在之后执行的定时任务。

#### 创建任务

| 场景 | 示例 | 说明 |
|---|---|---|
| 延迟执行一次 | `/loop in 30m 检查构建结果` | 30 分钟后执行一次，完成后自动删除。 |
| 延迟执行一次 | `/loop 1h 汇总当前排查结论` | `in` 可省略。 |
| 固定间隔执行 | `/loop every 15m 检查训练日志中的错误` | 每次执行完成后，计算下一次执行时间。 |
| 每天定时执行 | `/loop daily 09:00 汇总昨日测试结果` | 每天本地时间 09:00 执行。 |
| cron 表达式 | `/loop cron "0 9 * * 1" 汇总本周待办` | 使用五字段 cron：分、时、日、月、星期。 |

时间间隔支持秒、分钟、小时和天，例如 `30s`、`10m`、`2h`、`1d`。也可以直接用自然语言请求 Agent 创建任务，例如“每 30 分钟检查一次构建状态”；Agent 会在当前会话中调用定时任务工具。

若未在命令中提供任务内容，`/loop` 会读取当前工作目录下的 `loop.md` 作为默认提示词：

```text
/loop every 1h
```

适合将固定的巡检说明、报告模板或检查清单写入 `loop.md`，避免每次重复输入。

#### 管理任务

| 命令 | 说明 |
|---|---|
| `/loop list` | 列出任务 ID、类型、执行计划、下次执行时间、已执行次数和过期时间。 |
| `/loop cancel <task-id>` | 取消指定任务。 |
| `/loop stop` | 清空当前会话的全部定时任务。 |

#### 推荐场景

- **延迟跟进**：例如“30 分钟后检查构建或测试是否结束”。
- **周期性巡检**：例如定期检查训练日志、服务状态或目录中新生成的结果文件。
- **固定节奏的汇总**：例如每天生成测试进展、待办事项或运行状态摘要。
- **需要等待的多步骤工作**：先让 Agent 启动或分析一个耗时操作，再安排后续检查和汇总。

#### 使用限制

- 任务仅保存在当前 Session 的内存中，退出会话或进程后不会恢复。
- 单次任务成功或失败后会被删除；循环和 cron 任务会重新计算下一次执行时间。
- 每个会话最多保留 50 个任务，任务默认在创建 7 天后过期。
- 定时任务以“会话空闲时执行”为原则，不适用于必须在精确时间触发、需要跨进程持久化或长期无人值守运行的场景。

### 输入区快捷键

| 快捷键 | 说明 |
|---|---|
| `Ctrl+C` | 有输入时清空输入框；连续按两次退出会话。 |
| `Ctrl+J` | 插入换行，便于多行输入。 |
| `Shift+Tab` | 循环切换审批模式。 |
| `Ctrl+B` | 切换 bash mode。 |
| `Ctrl+K` | 直接打开快捷键说明。 |
| `Ctrl+O` | 打开最近一次可展开的工具输出。 |
| `Tab` | 应用第一个补全项。 |
| `Enter` | 提交输入；如果当前选中了补全项，则先应用补全。 |

### 工具输出查看器

当某次工具调用支持展开查看时，可用 `Ctrl+O` 或 `/tool-output` 打开工具输出查看器。查看器内支持：

- 左右方向键：切换不同工具调用输出
- 上下方向键、`PageUp` / `PageDown`、`Home` / `End`：滚动内容
- 点击、`Ctrl+O` 或 `Enter`：展开或折叠完整输出
- `Esc`：关闭查看器

### 长期记忆

`msagent` 支持把需要跨会话保留的信息保存为项目本地记忆。记忆内容会写入当前工作目录的 `.msagent/memory.md`，后续会话启动和消息处理时会自动读取非空记忆并注入上下文。

| 命令 | 说明 |
|---|---|
| `/remember <content>` | 追加一条长期记忆，例如 `/remember 用户希望所有回答默认使用中文`。 |
| `/showmemory` | 展示当前项目已保存的记忆；如果还没有有效记忆，会提示暂无内容。 |

适合保存的内容包括用户偏好、项目约定、长期有效的路径说明、排查结论或后续任务需要持续参考的背景事实。不建议保存密钥、令牌、密码等敏感信息。
