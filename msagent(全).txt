  若要获取显存相关的精确指标（每步内存峰值、内存碎片、alloc/free 时序），需要重新采集并设置：                                                                        

  torch_npu.profiler.profile(

      profile_memory=True,   # ← 需要设为 True

  ▌  1 Rank 3 Free 时间 13.3ms（远超均值 10.2ms）→ NPU 空闲/饿死

  ▌  3 Rank 3 最早启动的 allReduce 反而有最大耗时 → 它在等别人时才展现正常时间                                                                                     
  ▌  4 slowRank 显示 Rank 3 影响其他卡次数 64 次 → 明确慢卡标签

  本 profiling 数据的首要瓶颈不是通信带宽，而是 Host CPU 侧算子下发延迟导致的 Rank 间等待。 实际 HCCS 传输带宽（~15 GB/s）在合理范围内，无硬件链路故障。
