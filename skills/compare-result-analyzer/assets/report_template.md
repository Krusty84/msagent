## 2. 判定标准说明

本报告采用 **NRE 为主、MeanBias 补充** 的双层判定标准，判断节点误差是否"不可忽略"：

| 判定层 | 条件 | 角色 | 说明 |
|--------|------|------|------|
| **NRE（主）** | NormRelativeErr >= 阈值 | 主信号 | 覆盖绝大多数场景。NRE 为整体向量级别偏差，对范数级别的误差最为敏感。 |
| **MeanBias（补充）** | MeanBias >= α × 阈值（α = 1.2） | 补充信号 | 捕获 NRE 未检测到的**整体均值偏移**——衡量两个 tensor 的整体性偏移程度。 |

**MeanBias 定义**：

```
MeanBias = |Mean diff| / Bench L2norm
```

- `Mean diff`：NPU tensor 与 Bench tensor 分别计算均值后的差值（`Mean diff = mean(NPU tensor) − mean(Bench tensor)`），来自比对 CSV 的 `Mean diff` 列。CSV 中所有数值列均为 tensor 级聚合统计量，非逐元素比较结果。
- `Bench L2norm`：Bench tensor 的 L2 范数，来自比对 CSV 的 `Bench l2norm` 列。
- MeanBias 为**原始比率**（0 ~ +inf），转换为百分比时乘以 100。
- **判定系数 α = 1.2**：MeanBias 的补充阈值为 `α × 阈值`（例如阈值为 1%，则 MeanBias >= 1.2% 时触发补充判定）。α 表示允许的 bias 漂移占整体幅值变化的比例，α ≈ 1.2 可在保证检测整体偏置的同时，降低因统计波动导致的误报。
- MeanBias **不是原始比对 CSV 的列**，由分析脚本根据 `Mean diff` 和 `Bench l2norm` 计算得出。

**NRE 与 MeanBias 的关系**：
- 仅当 NRE < 阈值时，才检查 MeanBias 补充。NRE 已超标的节点直接判定为"不可忽略"，不再依赖 MeanBias。
- MeanBias 补充主要捕获**方向性差异**——各元素误差方向一致（系统性偏高/偏低），导致 Mean diff 绝对值大，但向量整体范数偏差（NRE）可能不大。
- 报告中所有"需关注"、"不可忽略"、"问题节点"等判断，均基于此双层标准。

## 4. 首问题点

> ⚠️ **重要**：首问题点**必须经过上下游传播检查后才能确认**，不能仅凭首个 output 不可忽略就认定：
> 1. 按执行顺序找到首个触发不可忽略判定的 OUTPUT 节点

## 5. 误差传播分析

> ⚠️ **过滤规则**：本章所有子节（§5.1~§5.6）**均不展示行号范围起始值小于首问题点行号范围起始值的节点**。这些节点已在 §4 首问题点发现链中完整记录。仅展示行号范围起始值 >= 首问题点行号范围起始值的节点。
>
> 以下表格为五种误差传播形态的定义速览，按关注优先级从高到低排列。

| 分类 | 条件 | 含义 | 结论 |
|------|------|------|------|
| **误差引入点** | 某 input < 阈值 → 某 output >= 阈值（NRE 为主/MeanBias 补充） | 算子**引入**了新误差 | 需排查 |
| **误差放大点** | 某 input >= 阈值 → 某 output > 该 input（超出相对容差 0.1%） | 算子**放大**了已有误差 | 需排查 |
| **误差缩小点** | 某 input >= 阈值 → 某 output >= 阈值，且 output < 该 input（超出相对容差 0.1%） | 输出误差较输入**缩小**，精度影响有限 | 排查优先级较低 |
| **误差继承** | output 误差 >= 阈值 且 与某 input **多维度一致**（NRE+类型+平均相对误差+最大相对误差） | 该 output 误差**继承**自上游，算子对该 output 无责 | 无需关注 |
| **误差消除** | 某 input >= 阈值 → 某 output < 阈值 | 误差被**消除** | 无需关注 |

> ⚠️ 各分类采用**复合优先级规则**——多 input 算子中，若存在至少一条"干净 input → 脏 output"路径则整体标记为"误差引入"（不再同时标记"误差缩小"）。同一 (prefix, direction) 不再出现双标签。显著放大算子（Jump > 2×）已移入 §5.1a 独立呈现。
>
> ⚠️ **判定前提与修正**：
> - **继承排除**：output 误差与某 input 多维度一致（NRE+类型+平均相对误差+最大相对误差）→ 归"误差继承"，不判"误差引入"
> - **数据输入优先**：若算子的数据输入已脏（`input.X` 而非 `parameters.X`），仅当 `output NRE > max(数据输入 NRE) × 1.1` 才判"误差引入"，否则按"误差缩小"/"误差放大"处理
> - **参数梯度独立评估**：反向参数梯度（weight/bias 的梯度）不参与 input→output 传播比较，NRE ≥ 阈值直接判"误差引入"

### 5.1 误差引入点（干净输入 → 脏输出）：精度问题引入点
