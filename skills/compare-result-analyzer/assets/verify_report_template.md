# 单算子验证报告

> **用途**: 本文件为 compare-result-analyzer skill 的单算子验证报告模板。生成报告时，agent 必须按此模板的章节结构和表格格式输出。
>
> **背景**: 比对分析报告 §3 列出了可疑候选 API 算子（如 `Tensor.__truediv__.3.backward`）。单算子验证用 NPU 统计值构造输入，在 CPU 和 NPU 上分别跑同一算子，逐一对比输出——这是实锤级别的验证。

**核心术语**：

| 术语 | 含义 |
|------|------|
| **NRE**（归一化相对误差） | = L2 diff / Bench l2norm（原始比率，转百分比时 ×100）。主判定指标，≥ 阈值判"不可忽略" |
| **MeanBias**（整体均值偏移） | = \|Mean diff\| / Bench l2norm。NRE 未超标时的补充判定指标（α × 阈值，α=1.2） |
| **误差引入点** | 传播形态：算子**引入**新误差（干净输入 → 脏输出），精度问题引入点，优先排查 |
| **误差放大点** | 传播形态：算子**放大**上游已有误差（脏输入 → 更脏输出） |

> 详细分类判定规则见比对分析报告 §5 传播跳变分析。

## 附录：dtype 自适应容差

验证时使用的 atol/rtol 按算子输出 dtype 自适应选取。若用户通过 CLI 显式传了 `--atol` / `--rtol`（与 float32 fallback 不同），则优先使用用户指定值。

| dtype | atol | rtol | max_rel_err 阈值 | 依据 |
|---|---|---|---|---|
| float64 | `1e-9` | `1e-7` | 0.00001% | 双精度，CPU/NPU 差异应极小 |
| float32 | `1e-4` | `1e-3` | 0.1% | ≈840× eps，matmul K=1024 累加误差 ≈1.2e-4 |
| float16 | `1e-3` | `1e-3` | 0.1% | ≈1× eps(9.77e-4)，元素级操作可过 |
| bfloat16 | `5e-3` | `5e-3` | 0.5% | ≈0.6× eps(7.81e-3)，元素级操作可过 |

> 判定公式：`passed = shape_match AND (max_diff < atol_dtype) AND (max_rel_err < rtol_dtype × 100)`
