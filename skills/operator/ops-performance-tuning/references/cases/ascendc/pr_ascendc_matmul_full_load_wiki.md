## 问题与瓶颈
MatMul 左右输入一路很小、另一路很大时，通用切分会重复搬运小矩阵，导致 MTE/L1 流量和搬运轮次高于必要值。

## 优化方法（理论手段）
1. **小矩阵全载**：把较小的一路完整装入片上层级，在多轮大矩阵切分中复用，减少重复 GM→L1/L0 搬运。
2. **按左右矩阵选择模板**：分别评估 A 全载与 B 全载，选择能满足 L1/L0 容量且复用次数更高的一侧。
3. **容量与流水共同约束**：全载后重新预算 L1/L0A/L0B，避免挤占 double buffer 空间导致流水反而变差。

## 适用范围与警示
- 适用于一侧 K/M/N 维明显较小且能装入片上存储的 MatMul。
- 两侧都大或复用不足时不适用；必须结合 MTE active bandwidth、L2/L1 流量与容量模型判断。
- 全载模板在 A2/A3/A5 的容量和 API 能力不同，必须按目标 SoC 重算 Tiling。
