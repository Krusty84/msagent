# 回退流程、锚点与置信度

本 Skill 只回答「哪些层需要回退」。回退操作本身由量化/EP 调优 Skill 执行，本文件给出回退的决策树、候选顺序、锚点/回滚与证据置信度。

## 1. 决策树

```text
取得真实模块名 + 模型结构 + 量化格式
  ├─ 结构/模块名无法确认 → 不生成回退项，先补结构映射
  ├─ MoE/EP → 进入 moe_model_rules.md
  ├─ Dense GQA/MHA/MLA/VLM/DiT/扩散 → 进入 dense_model_rules.md
  └─ DSA/SWA/GatedDeltaNet → expert_experience.yaml 优先保持 BF16
```

不要仅因出现 `gate`、`o_proj`、`down_proj`、`experts` 字符串就套规则。必须确认父模块、结构类型与实际量化范围。

## 2. 回退手法（术语）

- **结构化回退**：按模块模式或结构块排除量化，如 `*gate`、`*mlp.down_proj`、`*kv_b_proj`、`*mlp.shared_experts.*`。
- **提级回退**：低比特模型中把某模块提到高精度档位，如 W4A8 中把 `model.layers.<i>.mlp.experts*` 单列 W8A8。
- **逐层回退**：仅当结构化候选仍精度不足时，对敏感层逐个或小批次恢复高精度。
- **锚点**：已验证可接受的配置版本，含 YAML、权重、精度结果与日志关联。

## 3. 候选生成顺序

1. 已有实践明确排除 / BF16 的结构：保持高精度。
2. MoE `gate`/`router`：确认是否已排除；未排除且路由相关精度异常时优先处理。
3. `shared_experts`：确认高精度档位（有证据保持，无则待验证）。
4. 按格式确定低比特落点（W4A8/W4A4 的 experts）与敏感层专家提级（如 `model.layers.<i>`）。
5. `mlp.down_proj` / `o_proj`：按 YAML 层范围生成结构化候选（`exclude` 增加 `*.mlp.down_proj` / `*.o_proj`，单层投影保持浮点，而非整层回退）。
6. MLA 等特殊投影：仅在结构存在且有证据时处理。
7. 首尾层保护：仅在目标实践或敏感性分析支持时增加。
8. 普通 attention/FFN 主体：最后考虑，且用敏感层结果，不做整体盲退。

## 4. 每轮闭环

```text
生成一项结构化回退
  → 记录 YAML 差异与权重目录
  → 执行量化与全集/压缩集测评（与浮点基线同口径）
  → 达标：保留并固化（更新锚点）
  → 未达标：撤销或扩大同类候选（只改一类手段，避免多变量同变）
  → 多轮无效：回到结构映射与数据集一致性检查
```

## 5. 失败处理

- 回退后精度无改善：撤销该变更，检查数据集一致性、YAML 是否实际生效与推理加载路径。
- 改善但成本过高：缩小到敏感层或特殊模块，重新测评。
- 约束内仍无法兼顾：提高位宽、放宽目标或暂缓方案；单纯加大回退虽逼近浮点但失去量化收益，不作为默认出路。
- 每次变更都与最近锚点比较，保留「通过精度门槛且高精度模块最少」的配置。

## 6. 证据与置信度

| 等级 | 判定 |
|---|---|
| 高 | 多份独立实践 YAML 对同一结构+模块模式采取相同排除/回退 |
| 中 | 单个实践明确配置，或多个文件相近但不完全一致 |
| 低 | 仅由 expert_experience.yaml 结构映射/代码逻辑/模块名推断，无回退结果 |

当前可确认方向：
- `gate`/`router` 排除、`shared_experts` 保持高精度、`kv_b_proj` 等低秩投影排除、experts 作为 W4A8/W4A4 低比特落点：多文件一致，置信度高。
- `mlp.down_proj` 回退：调优指南点名为高敏感层，实践高频出现但层范围不统一，置信度中；不能固定为全模型全层。
- DSA/SWA/GatedDeltaNet = `bf16`：结构保持高精度证据，非量化后测评结论。
- W4A4 结构化排除：来自实践 YAML，但非 `expert_experience.yaml` 正式支持，置信度中。

## 7. 输出要求

建议同时写出证据等级与限制条件。无足够证据时用「候选/待验证」，不用「必然」「所有模型都」「一定提升」。最终接受条件由实际量化全集精度、浮点基线与运行证据决定。

## 记录格式

每条规则记录：`source`（YAML/代码/指南路径）、`quant_type`（量化格式）、`structure`、`module_pattern`、`layer_scope`、`action`（排除量化/恢复高精度/提级/保持量化/待验证）、`evidence`（重复实践/单实践/指南结论/代码映射/实测）、`confidence`（高/中/低）、`validation`（仍需执行的验证）。不同结构的层号与模块前缀不得直接合并。
